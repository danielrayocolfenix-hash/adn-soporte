# adn-soporte

Carpeta de trabajo local, **no es un repositorio git**. Contiene dos
repositorios independientes que juntos forman el módulo de soporte
técnico/QA de ADN-VORTEX:

- [`backend/`](backend/) — API Django (arquitectura hexagonal). Ver
  [backend/README.md](backend/README.md).
- [`frontend/`](frontend/) — SPA React + TypeScript (arquitectura modular).
  Ver [frontend/README.md](frontend/README.md).

Cada carpeta se versiona, se despliega y se documenta por separado. Este
archivo es solo orientación local; no viaja a ningún remoto.
